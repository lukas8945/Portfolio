Veille Technologique

Sujet : Le Single Sign-On (SSO)

Cybersécurité Gestion des identités SISR

Présentation du sujet

Le SSO est un système d'authentification qui permet à un utilisateur d'accéder à plusieurs applications informatiques en ne procédant qu'à une seule authentification. Dans mon entreprise, cette solution est cruciale pour simplifier l'expérience utilisateur tout en sécurisant les accès.

Fonctionnement Technique

Le flux repose sur l'échange de jetons (Tokens) entre un Fournisseur d'Identité (IdP), comme Microsoft Entra ID ou Okta, et les Fournisseurs de Services (SP).

  • SAML 2.0 : Utilisé pour les applications lourdes ou métiers.
  • OpenID Connect : Utilisé pour les applications Web modernes.

Analyse pour le BTS SISR

Avantages : Centralisation des comptes, réduction des appels au support pour mots de passe oubliés, application du MFA (Multi-Factor Authentication) sur un point unique.

Risques : "Single Point of Failure" (si le serveur SSO tombe, tout est bloqué) et nécessité de sécuriser drastiquement le compte maître.
